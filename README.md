# Realm

One World of Warcraft: Forever addon: a leveling route with a top-centre compass, quest automation and class trainer stops, auto-sell and repair, party tracker, Exchange auction scanner, death counter, and gear and class guides.

## Install
1. Download `Realm.zip` from this repo.
2. Unzip it into your `_forever_\Interface\AddOns\` folder so you end up with `AddOns\Realm\Realm.toc`.
3. Restart the game or type `/reload`.

Current version is listed in `version.json`.

Scope: World of Warcraft: Forever only, for now.
